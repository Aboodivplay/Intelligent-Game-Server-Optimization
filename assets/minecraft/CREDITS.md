# Minecraft workspace artwork

The homepage shows the default title-screen panorama from Minecraft Java Edition 26.3 (Wilderness Bound). The workspace switches to the Trails & Tales panorama for servers configured for 1.20.1. Both images are cropped, joined views of the original game panoramas.

- [Minecraft Java 26.3 release](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3)
- [Minecraft Java 1.20.1 panorama source files](https://github.com/InventivetalentDev/minecraft-assets/tree/1.20.1/assets/minecraft/textures/gui/title/background)

The crafting table, TNT, diamond ore and grass block show the default Java 26.3 textures in an inventory view. The workspace also uses the default item sprites, oak planks and stone. The link cursor uses the game's iron pickaxe. The crosshair is drawn for this site.
